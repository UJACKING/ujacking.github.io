# Contribuir

Esta web se mantiene entre toda la comunidad. Si has encontrado un error, quieres añadir un recurso o
redactar una página nueva, **eres bienvenido**. No hace falta ser experto: revisar y corregir también
es contribuir.

[Leer la guía completa de contribución](https://github.com/UJACKING/ujacking.github.io/blob/main/CONTRIBUTING.md){ .md-button .md-button--primary }

## Resumen del flujo

1. **Fork** del repositorio `UJACKING/ujacking.github.io`.
2. Crea una **rama** descriptiva (`docs/mi-cambio`).
3. **Edita** los ficheros Markdown de `docs/`. Puedes previsualizar con `mkdocs serve`.
4. **Commit** con la convención `tipo: descripción` (en español).
5. Abre un **Pull Request** hacia `main`.

## Antes de abrir tu PR

- [ ] `mkdocs build --strict` pasa sin warnings.
- [ ] Los enlaces funcionan o están marcados como `TODO-UJACKING`.
- [ ] No hay contenido copiado.
- [ ] No hay secretos (tokens, contraseñas).
- [ ] Has usado la plantilla de página (si es Nivel 1).

## Formas de contribuir

| Quiero… | Cómo |
| --- | --- |
| Reportar un enlace roto | Abre un issue con la plantilla *Enlace roto*. |
| Corregir un error | Issue *Error en contenido* o directamente un PR. |
| Proponer un recurso | Issue *Proponer un recurso*. |
| Proponer un tema nuevo | Issue *Propuesta de tema*. |
| Redactar una página | Abre un PR siguiendo la [plantilla](https://github.com/UJACKING/ujacking.github.io/blob/main/CONTRIBUTING.md). |
