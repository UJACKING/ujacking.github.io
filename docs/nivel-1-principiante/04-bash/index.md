# Módulo 04 · Bash

**La línea de comandos es el taller donde se trabaja la ciberseguridad.** Todo lo que hagas en
Linux —escaneos, análisis de logs, automatización— pasa antes o después por un shell. En este módulo
aprendes a moverte por la terminal con soltura, a encadenar comandos y a escribir tus propios
scripts en Bash.

No hace falta saber programar: empezamos desde "¿qué es una terminal?" y terminamos con scripts
útiles de verdad que puedes reutilizar.

[Empezar por Terminal, shell y consola](01-terminal-shell-y-consola.md){ .md-button .md-button--primary }

## ¿Qué necesito para practicar?

- Un Linux funcionando (o una máquina virtual con Kali, Parrot o Ubuntu). Lo montamos en el módulo
  de [Sistemas operativos](../03-sistemas-operativos/index.md).
- Nada más. La terminal ya viene instalada en cualquier Linux.

!!! tip "Cómo aprovechar este módulo"
    Ten la terminal abierta al lado. La única forma de aprender Bash es **teclear**: copia, pega,
    equivócate y arregla el error. Leer comandos sin ejecutarlos no sirve de nada.

## Orden recomendado

1. Lee **01** para entender qué es el shell y abrirlo.
2. Trabaja **02** y **03** con la terminal delante; son la base de todo.
3. Escribe los scripts de **04** y guárdalos: te servirán en el resto de la web.
4. Deja **05** abierta en una pestaña: es tu chuleta de consulta diaria.
