# Módulo 05 · Git y GitHub

**Git es el sistema de control de versiones que usa todo el mundo profesional.** No es solo para
programadores: sirve para guardar tu trabajo, volver atrás cuando la lías, colaborar y —muy
importante— **construir tu portfolio público**. En este módulo aprendes Git desde cero y luego GitHub:
repositorios, ramas, Pull Requests, Pages y tu perfil.

Acabamos conectando todo con algo muy concreto: **cómo publicar la web que estás leyendo** y cómo
contribuir a ella.

[Empezar por Control de versiones](01-control-de-versiones.md){ .md-button .md-button--primary }

## ¿Qué necesito?

- Un ordenador con **Git instalado** (lo hacemos en la página 02).
- Una cuenta en [GitHub](https://github.com) (**Gratis**).
- Una terminal. Aquí se aprovecha todo lo aprendido en el [módulo de Bash](../04-bash/index.md).

!!! danger "Un secreto subido a GitHub es un secreto comprometido"
    Aprenderás esto a fondo en la página de Pull Requests, pero grábatelo desde ya: **nunca subas
    contraseñas, claves privadas ni tokens**. Un repositorio público es visible para el mundo entero.

## Orden recomendado

1. **01** para entender el concepto.
2. **02** para dominar `add`, `commit`, `status` y configurar Git con SSH.
3. **03** para trabajar con ramas, que es como se colabora de verdad.
4. **04** para llevar tu trabajo a GitHub con Pull Requests.
5. **05** para publicar webs y dejar tu perfil brillante.
