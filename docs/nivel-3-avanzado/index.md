# Nivel 3 · Avanzado

Páginas breves y honestas sobre **certificaciones ofensivas**. El objetivo no es venderte un examen,
sino que sepas **a quién va dirigido cada uno** y **cómo prepararlo con recursos gratuitos** antes de
gastarte dinero.

!!! warning "Precios, formato y condiciones"
    Todo lo relativo a precio, formato, número de máquinas y condiciones del examen **cambia con el
    tiempo**. Aquí no inventamos detalles: cada página te dice qué debes **comprobar en la web
    oficial** antes de inscribirte. Los datos concretos que falten quedan marcados como
    `TODO-UJACKING`.

## Cómo preparar cualquier certificación (patrón general)

1. **Lee la web oficial** y apunta los requisitos exactos (temario, formato, vigencia).
2. **Estudia por el temario**, no por la certificación: si entiendes los conceptos, el examen es el
   trámite.
3. **Practica en plataformas** como [Hack The Box](../nivel-1-principiante/06-donde-practicar/02-hack-the-box.md)
   o [TryHackMe](../nivel-1-principiante/06-donde-practicar/01-tryhackme.md).
4. **Mide tu nivel** con máquinas de práctica antes de pagar un examen.
5. **Documenta** lo que haces: te servirá para el CV y para [writeups](../empleabilidad/writeups.md).
